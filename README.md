Entry for the make.fun bounty "Warning Label for Humans: One Line, Big Laugh": a program that writes one single-line safety warning label for every human being (at most 160 characters) to `/output/entry.txt`.

The label:

> CAUTION: This human was assembled without instructions, has no warranty, and will press every button marked DO NOT PRESS.

Run: `node main.ts` (Node 22). Output directory can be overridden with `MAKEFUN_OUTPUT_DIR`.
